# Global guidance

Personal, machine-wide guidance for Claude Code. Applies to every project;
project-specific rules belong in that repo's own CLAUDE.md.

Managed by home-manager — edit the source at
`~/.config/home-manager/home/claude/CLAUDE.md`, then run `hms`. The live file at
`~/.claude/CLAUDE.md` is a read-only Nix symlink and must not be edited directly.

## Environment

- macOS (aarch64), Nix + nix-darwin + home-manager (flake at `~/.config/home-manager`).
- Apply changes with `hms` (home-manager) / `dws` (darwin); see aliases in `home/zsh.nix`.
